# Game functions replaced by runtime C implementations (Chrono Trigger DS).
# Format: <module> <address> <C function> [wrap] [jp=<address>]. Calls and the dispatch table use the runtime
# function instead. The recompiler emits no code for these, except with `wrap`: then the game function is still
# recompiled under its usual name (f_<module>_<address>) and the runtime function calls it. The address is the USA
# and European one; jp= is the Japanese one where it differs.

# NitroSDK thread context switching: register-file save/restore that has no C equivalent.
# Replaced by coroutine switches (runtime/thread.c).
main 020078d8 rt_os_save_context
main 02007924 rt_os_load_context
itcm 01ff8058 rt_os_irq_thread_switch

# C++ operator new failure (throws std::bad_alloc; the game then halts). Reported as a fatal error with
# the requested size, which operator new keeps in r6.
main 02023cb0 rt_bad_alloc

# New Game settings defaults: in single screen mode, Game Mode starts as Classic instead of DS

ov007 0212a3f0 rt_ct_settings_defaults wrap jp=0212a2c8

# Title idle timeout (30 s to the intro movie): held off while System Settings is open (runtime/patches.c).

# Field object visibility test (characters are drawn while their tile is within 4 tiles of the 4:3 view): in

ov004 02130dbc rt_ws_object_visible wrap

# Zoom out: a sprite's Y needs more than its 8 bits, and the UI's sprites stay at the original scale: what the
